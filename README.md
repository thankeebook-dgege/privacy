# Сайт ThankeeBook

Здесь лежит готовый сайт https://thankeebook.com — страницы на 24 языках и
политика приватности. Он выложен отдельно и открыто, потому что магазины
приложений требуют ссылку, которая открывается без входа.

**Руками здесь ничего не правится.** Все страницы собирает программа из
закрытого хранилища приложения (`tool/site/build.dart`), и следующая сборка
сотрёт любую ручную правку. Меняется вид или текст — меняется там, потом
пересобирается сюда.

На сайте нет скриптов, форм и чужих файлов; сборка это проверяет сама.

Исходный код приложения тут не хранится.
